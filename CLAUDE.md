## graphify

This project has a knowledge graph at graphify-out/ with god nodes, community structure, and cross-file relationships.

Rules:
- For codebase questions, first run `graphify query "<question>"` when graphify-out/graph.json exists. Use `graphify path "<A>" "<B>"` for relationships and `graphify explain "<concept>"` for focused concepts. These return a scoped subgraph, usually much smaller than GRAPH_REPORT.md or raw grep output.
- If graphify-out/wiki/index.md exists, use it for broad navigation instead of raw source browsing.
- Read graphify-out/GRAPH_REPORT.md only for broad architecture review or when query/path/explain do not surface enough context.
- After modifying code, run `graphify update .` to keep the graph current (AST-only, no API cost).

## Project: Fitopia — Expo 52 React Native Fitness App

**Stack:** Expo SDK 52 · React Native 0.76 · Supabase · React Navigation v6 · Reanimated v3 · AsyncStorage

**Key entry points:**
- `App.js` — root, tab navigator, auth state (AsyncStorage session via Supabase)
- `src/lib/supabase.js` — Supabase client, persistSession:true, AsyncStorage storage
- `src/utils/cache.js` — stale-while-revalidate cache (mem + AsyncStorage), TTL constants
- `src/utils/i18n.js` — `t(key, lang)` function, full TR/EN translations (63+ keys)
- `src/data/trainingPlans.js` — static plans with `name_en`, `description_en`, `dayOfWeek`
- `src/data/zoneData.js` — auto-generated muscle zone lookup tables (run scripts/process_assets.js)

**Screens:**
- `HomeScreen` — active program today card (tap → Program tab), weekly activity dots, stats
- `ExercisesScreen` — 3 tabs: Library (filter/search/pagination), Workouts (custom), Templates
- `ProgramScreen` — active program day cards, open state controlled by parent, media modal
- `ProgressScreen` — mascot (MascotFlipCard), measurements, overload charts
- `ProfileScreen` — avatar, body stats, gender, language, units

**Components:**
- `MascotFlipCard` — tap muscle → overlay PNG highlight → navigate to filtered exercises
- `ExerciseMedia` — expo-video WebM player, video outside ScrollView to prevent jump

**Contexts:** LanguageProvider · UnitsProvider · MuscleFilterProvider (mascot→exercises bridge)

**Performance patterns already in place:**
- `Promise.all` for parallel Supabase fetches in HomeScreen, ProgressScreen
- `React.memo` on ExerciseRow, DayCard in lists
- `stale-while-revalidate` via cache.js (EXERCISES 1hr, RATINGS 5min, PROFILE 10min)
- FlatList: `initialNumToRender=12`, `maxToRenderPerBatch=10`, `windowSize=5`
- `useFocusEffect` (not useEffect) — only refetch when screen gains focus

**Important rules:**
- Never push graphify-out/, KnowledgeBrain refs, or Obsidian data to git — .gitignore already covers graphify-out/
- `persistSession:true` + AsyncStorage → user stays logged in across app restarts
- `dayOfWeek` field on workouts (0=Sun,1=Mon…6=Sat) drives both HomeScreen card and ProgramScreen card opening
- Muscle zone overlays: assets/zones/{MF|MB|FF|FB}_{muscle}.png — generated by scripts/process_assets.js from mask PNGs
- All user-visible strings via `t(key, lang)` — no inline `lang==='tr'?X:Y` ternaries
